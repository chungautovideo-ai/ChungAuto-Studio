# Mẫu "Kim Cương Tím" (chủ đề: Chuyên gia chia sẻ chuyên sâu · Giáo dục) — "N lý do", huy hiệu kim cương, chữ phát sáng

Chuyên gia giải thích N lý do / N sai lầm: mở đầu 3 huy hiệu kim cương (1 sáng 2 mờ), mỗi lý do mở bằng bảng xanh đêm số lớn + huy hiệu,
câu thường là chữ trắng phát sáng ở ngực. Lớp CSS tiền tố `kc-`. Số đo: workspace/content/2026-10-30/mau-11/work.

## Chọn thẻ theo lời
- "có N lý do" → ba-kim-cuong. "Thứ nhất / hai / ba" → bang-so (đổi số + icon + tên). Câu thường → chu-sang.
- Câu then chốt → khung-sang. Liệt kê công cụ → nut-kinh.

## Nhịp, âm thanh, màu
- Bảng số 1,5–2s. deep-hit cho bảng số, pop cho huy hiệu / nút, shimmer cho khung. Tím #B9A6FF, xanh đêm, trắng phát sáng.
