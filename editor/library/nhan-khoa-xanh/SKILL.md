# Mẫu "Nhãn Khoa Xanh" (chủ đề: Chuyên gia chia sẻ chuyên sâu · Giáo dục) — chữ viết tay xanh ngọc, icon, ảnh cắt sóng

Chuyên gia ngồi bàn giải thích một hiểu lầm: thuật ngữ chính là chữ viết tay xanh ngọc phát sáng, điều gây sốc chữ viết tay đỏ,
câu thường là nhãn viên thuốc xanh. Lớp CSS tiền tố `nk-`. Số đo: workspace/content/2026-10-30/mau-08/work.

## Bố cục
- Chữ viết tay: ngang ngực lệch trái (y ≈ cằm + 300px). Nhãn xanh: giữa ngực. Icon nét: cạnh vai phía trống.
- anh-song / chia-doi: nửa trên khung, người vẫn thấy dưới.

## Chọn thẻ theo lời
- Thuật ngữ → tay-xanh; "điều bất ngờ / sai lầm" → tay-do; câu thường → vien-xanh.
- Nhắc đối tượng → icon-net / o-icon-trang. Sản phẩm / chủ đề → anh-song. So sánh → chia-doi. Chuyển đoạn → chop-trang.

## Nhịp, âm thanh, màu
- Chữ viết tay hiện dần trái → phải 0,6s. shimmer / deep-hit / pop / swish. Sáng, hơi lạnh, xanh ngọc #4FE3D8.
