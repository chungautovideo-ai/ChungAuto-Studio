# Lesson Structure — Pedagogical Guidelines

## 3E Framework (Explain → Example → Practice)

Áp dụng cho mỗi concept trong bài:

```
EXPLAIN   → Định nghĩa rõ ràng, không dài hơn 3 câu
EXAMPLE   → 1 ví dụ cụ thể từ thực tế (không ví dụ trừu tượng)
PRACTICE  → Câu hỏi nhỏ, mini-exercise, hoặc "thử áp dụng..."
```

Ví dụ áp dụng 3E cho khái niệm "Biến số":
- **E1 (Explain)**: Biến số là ô chứa dữ liệu trong lập trình. Bạn đặt tên cho nó và lưu giá trị vào đó.
- **E2 (Example)**: `ten = "Minh"` — biến `ten` giữ giá trị `"Minh"`. Thay đổi giá trị: `ten = "Lan"`.
- **E3 (Practice)**: Tạo 1 biến lưu tuổi của bạn. Tên biến là gì? Giá trị là gì?

## Level Guidelines

### Cơ bản (Beginner)
- Giải thích mọi thuật ngữ kỹ thuật
- Ví dụ từ cuộc sống hàng ngày
- Ít khái niệm per bài (3-5 max)
- Quiz dạng True/False hoặc Multiple Choice rõ ràng
- Duration: 5-8 phút

### Trung cấp (Intermediate)
- Assume biết nền tảng cơ bản
- Ví dụ có độ phức tạp vừa
- 5-8 khái niệm per bài
- Quiz có thể open-ended
- Duration: 8-12 phút

### Nâng cao (Advanced)
- Deep dive, edge cases
- Ví dụ từ production/real systems
- Diagram phức tạp (architecture, comparison)
- Lab exercise thay quiz
- Duration: 12-20 phút

## Beat Count Guidance

| Độ dài bài | Số beats | Cấu trúc |
|---|---|---|
| 4-6 phút | 6-8 beats | Intro + Hook + 2 sections (2 beats mỗi) + Takeaway + Quiz |
| 8-12 phút | 10-14 beats | Intro + Hook + 3-4 sections (2-3 beats mỗi) + Takeaway + Quiz |
| 15-20 phút | 16-22 beats | Intro + Hook + 5-6 sections + Diagram + Examples + Takeaway + Recap Grid + Quiz |

## Từ vựng chuẩn cho VO (tiếng Việt)

**Khi giới thiệu concept**: "... là...", "... nghĩa là...", "... được hiểu như..."
**Khi nối ý**: "Tiếp theo,", "Ngoài ra,", "Quan trọng hơn,", "Nói cách khác,"
**Khi chốt ý**: "Tóm lại,", "Nhớ rằng,", "Điểm mấu chốt là,"
**Khi cho ví dụ**: "Ví dụ:", "Hãy tưởng tượng:", "Giả sử:", "Trong thực tế,"
**Khi quiz**: "Câu hỏi:", "Bạn nghĩ sao?", "Thử áp dụng:"
**TRÁNH**: em dash (—), viết tắt không rõ, câu quá dài (> 20 từ/câu)
